HOW TO USE

FK ATC COM Trainer — User Guide

The trainer lets you practice realistic radio communication one stage at a time. VFR and IFR use the same basic workflow: configure the flight, tune the radio, listen to ATC or ATIS, transmit your response, review the feedback, and continue to the next stage.

01

Choose VFR or IFR

Select VFR Radio Trainer for VFR operations or IFR Radio Trainer for IFR clearances, departures, enroute communication, arrivals, and approaches.

02

Complete Flight Setup

Use the setup column on the left. Select the training level, departure and destination airports, aircraft type, callsign, starting location, runways, and requested altitude.

For IFR, also select the route type and approach type.

03

Apply the Setup

Select APPLY SETUP. The trainer rebuilds the scenario using your selected airports, runways, frequencies, aircraft, and training level.

Select Tap To Collapse if you want to hide the setup panel after configuration.

04

Read the Current Stage

The center panel shows the current facility, frequency, stage number, next stage, and the task you are expected to complete.

Read the instruction before transmitting because the trainer evaluates stage-specific items.

05

Tune the COM Radio

Use the + and − controls to tune the displayed target frequency. The radio must show READY before ATIS monitoring or a radio transmission is accepted.

06

Monitor ATIS

During an ATIS stage, tune the correct frequency and select MONITOR ATIS. Listen for the information code, runway, wind, ceiling, visibility, and altimeter.

The trainer carries the information code into later radio calls where appropriate.

07

Use Tap To Talk

Select TAP TO TALK once to start listening. Speak your complete transmission. Select it a second time to end and send.

The trainer evaluates the speech only after you end the transmission.

08

Allow Microphone Access

The first time you use Tap To Talk, your browser may request microphone permission. Allow access for the trainer website.

For reliable microphone operation, use HTTPS or localhost. Some embedded website frames may restrict microphone access.

09

Use Typed Transmission

You may type the pilot transmission instead of using the microphone and select SEND. This is useful for practicing phraseology or checking recognition issues.

10

Listen to ATC

Controller responses appear in the Radio Exchange column and are spoken aloud when browser speech synthesis is available.

Select SAY AGAIN to replay the most recent controller transmission.

11

Read Back Required Items

Depending on the stage, the trainer checks runway, altitude, heading, frequency, squawk, hold-short instructions, route, taxi instructions, approach clearance, or other required information.

Your full callsign remains acceptable even after ATC abbreviates it.

12

Review Score and Feedback

After each transmission, review the stage score and feedback. If information is missing or incorrect, ATC may ask you to repeat or verify part of the readback.

Repeat the transmission until the essential items are accepted.

13

Move to the Next Stage

When a stage is completed, NEXT becomes available. The trainer also shows the next facility and frequency.

Use PREVIOUS to review an earlier stage.

14

Training Levels

Beginner provides more prompting and fewer unexpected changes. Intermediate reduces prompting and introduces more variation. Advanced provides minimal prompting and the most unexpected changes.

15

Unexpected ATC Changes

Depending on training level and scenario, ATC may issue runway changes, amended altitudes, different departure directions, stand-by instructions, unable responses, extended downwind, or go-around instructions.

Respond to the new clearance rather than repeating the original plan.

16

Training Log and Flight Report

Completed sessions are added to the Training Log. At the end of a flight, use the Flight Report to review the session, repeat the same route, or start another flight.

VFR WORKFLOW

Typical VFR Sequence

Departure ATIS → Clearance / Flight Following → Ground → Tower → Departure → Enroute when applicable → Arrival ATIS → Arrival / Approach → Destination Tower → Destination Ground.

IFR WORKFLOW

Typical IFR Sequence

Departure ATIS → IFR Clearance → Ground → Tower / IFR Release → Departure → Enroute → Arrival ATIS → Approach → Destination Tower → Destination Ground.

IMPORTANT

Training Use Only

FK ATC COM Trainer is a communication training aid. Frequencies, airport profiles, taxi routing, clearances, and scenarios may not represent current operational conditions. For an actual flight, use current FAA publications, charts, airport information, ATIS/AWOS/ASOS, and ATC instructions.
